Drei Versionen, die Dir begegnen







2.0 „Swagger“


Die alte Fassung. Noch weit verbreitet, aber anders aufgebaut: Schemas liegen
unter definitions, es gibt kein content mit Medientypen.
Wer ein Dokument findet, das mit swagger: "2.0" beginnt, sollte nicht
nach components suchen.






3.0


Der heutige Normalfall. Alles, was hier gezeigt wird, gilt. Von jedem Werkzeug
unterstützt.






3.1 empfohlen für Neues


Vollständig kompatibel zu JSON Schema – Schemas lassen sich damit zwischen API
und anderen Werkzeugen teilen. Vor der Festlegung prüfen, ob die eigene
Werkzeugkette sie schon versteht; manche hinken hinterher.







Format: YAML oder JSON, beides gleichwertig.
YAML zum Schreiben – lesbarer und mit Kommentaren. JSON zum Verarbeiten.
